# Bristol Community Events

## Project Overview

Bristol Community Events is a web-based event booking and management system developed using Python Flask and MySQL.

The system allows members of the public to browse community events, create an account, book tickets and view their previous bookings. It also provides an administrator area for creating, editing, cancelling and reviewing events.

This project was created for the UFCFES-30-1 Web Development and Databases module.

## Main Features

### User Features

Users can:

- Register for an account
- Log in and log out securely
- Browse available events
- View full event information
- View ticket prices and remaining capacity
- Book one or more tickets
- Enter lead attendee information
- Complete a simulated payment
- Receive a unique booking reference
- View a booking confirmation
- View previous bookings
- Print booking confirmation details

### Administrator Features

Administrators can:

- Access a protected administrator dashboard
- View total events, bookings, tickets sold and revenue
- Create new events
- Edit existing events
- Cancel events
- View event bookings
- View attendee information
